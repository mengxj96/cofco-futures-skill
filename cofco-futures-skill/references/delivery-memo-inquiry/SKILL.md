# 交割备忘录查询  
  
## 触发条件  
  
当用户询问交割备忘录相关内容时触发：  
- "交割备忘录"、"备忘录查询"、"交割记录"、"交割内容"  
- "卖方交割备忘录"、"买方交割备忘录"、"交割备注"  
- 包含具体日期的查询："2025年1月2号的交割备忘录"、"查询1月2号的备忘录"  
- 任何包含"备忘录"关键词的交割相关询问  
  
**注意**：与 `delivery-inquiry` 的区别：  
- `delivery-inquiry`：查询期货交易日历中的交易信息  
- `delivery-memo-inquiry`：查询具体的交割备忘录详细内容（卖方、买方、备注等）  
  
## 参数提取规则  
  
### 日期处理（必选）  
  
**日期识别规则**：  
- 用户必须提供日期信息，否则不执行查询，必须先引导用户提供  
- 日期可以是**具体某一天**：`"2025年1月2日"`、`"2025-01-02"`、`"20250102"`  
- 日期可以是**一个范围**：`"2025年1月"`、`"2025年1月1日到1月31日"`、`"1月2号到2月2号"`  
- 范围**最多不超过31天**，否则提示用户缩小范围  
- 日期格式统一转换为 **YYYYMMDD** 格式（例如：20250102）传递给工具  

### 品种处理（必选）  

**品种识别规则**：  
- 用户必须提供品种信息，否则不执行查询，必须先引导用户提供  
- 品种可以是**中文名称**：`"豆粕"`、`"螺纹钢"`、`"白糖"`、`"铜"`等  
- 品种需要查询转换为对应的**品种代码**后再传递给工具

**品种缺失处理**：
用户未提供品种时，必须先进行主动询问：  
> "请问您需要查询哪个品种的交割备忘录？您可以提供品种名称（如'豆粕'、'螺纹钢'、'铜'等），我会自动转换为对应的品种代码。"  

### 日期和品种都缺失的处理  
**品种和日期任一条件缺失，就不进行查询，必须先引导客户提供**
当用户既没有提供日期也没有提供品种时，按以下顺序询问：  
1. 先询问日期  
2. 再询问品种  

> "请问您需要查询哪一天的交割备忘录？您可以指定具体日期（如'2025年1月2日'或'20250102'），或者一个日期范围（如'2025年1月1日到1月31日'），日期范围最多不超过31天。"  
>   
> "另外，请问您需要查询哪个品种的交割备忘录？您可以提供品种名称（如'豆粕'、'螺纹钢'、'铜'等）。"  

### 可选筛选条件  
  
- `exchange_id_name`：交易所名称（大连商品交易所、上海期货交易所、郑州商品交易所、中国金融期货交易所等）
- `contract_id`：合约代码（如M2505、RB2505等）  
  
## 调用工具  
  
调用 `query_delivery_memo` 工具，参数构造示例：  
  
### 参数构造规则  
  
| 用户输入 | 提取结果 | 参数传递                                                                                            |  
|:---|:---|:------------------------------------------------------------------------------------------------|  
| "查1月2号的备忘录" | 只有日期，缺少品种 | **先询问品种**                                                                                       |  
| "查豆粕的备忘录" | 只有品种，缺少日期 | **先询问日期**                                                                                       |  
| "查1月2号豆粕的备忘录" | 日期+品种 | `start_date`: "20250102", `end_date`: "20250102", `variety_id`: "M"                             |  
| "查2025年1月2号螺纹钢的备忘录" | 精确日期+品种 | `start_date`: "20250102", `end_date`: "20250102", `variety_id`: "RB"                            |  
| "查20250102铜的备忘录" | 精确日期（YYYYMMDD格式）+品种 | `start_date`: "20250102", `end_date`: "20250102", `variety_id`: "CU"                            |  
| "查1月2号到1月31号豆粕的备忘录" | 日期范围+品种 | `start_date`: "20250102", `end_date`: "20250131", `variety_id`: "M"                             |  
| "查1月2号到2月15号豆粕的备忘录" | 超出31天+品种 | 提示用户范围超限，需要缩小                                                                                   |  
| "查1月2号大连交易所豆粕的备忘录" | 日期+交易所+品种 | `start_date`: "20250102", `end_date`: "20250102", `exchange_name`: "大连商品交易所", `variety_id`: "M" |  
 
### 使用示例  
  
**单日查询**：用户问"帮我查询2025年1月2号豆粕的交割备忘录" -> 调用 `query_delivery_memo`
```json
{ 
  "start_date": "20250102", 
  "end_date": "20250102"
}
```

**范围查询**：用户问"查询2025年1月1日到1月15日螺纹钢的交割备忘录" -> 调用 `query_delivery_memo`
```json
{ 
  "start_date": "20250101", 
  "end_date": "20250115", 
  "variety_id": "RB"
}
```

**按交易所筛选**：用户问"帮我查询2025年1月2号的大连商品交易所豆粕的交割备忘录" -> 调用 `query_delivery_memo`

```json
{ 
  "start_date": "20250102", 
  "end_date": "20250102", 
  "exchange_name": "大连商品交易所", 
  "variety_id": "M"
}
```

**按品种筛选**：用户问"查询2025年1月2号的豆粕交割备忘录" -> 调用 `query_delivery_memo`
```json
{ 
  "start_date": "20250102", 
  "end_date": "20250102", 
  "variety_id": "M"
}
```

**完整筛选**：用户问"查2025年1月2号大连交易所豆粕M2501合约的备忘录" -> 调用 `query_delivery_memo`
```json
{ 
  "start_date": "20250102", 
  "end_date": "20250102", 
  "exchange_name": "大连商品交易所", 
  "variety_id": "M", 
  "contract_id": "M2501"
}
```
