# 期货交易数据查询

## 触发条件

当用户询问交易相关内容时触发：
- "交易内容"、"交易日"、"交易查询"
- 包含具体日期的查询："2025年1月2号"、"查询1月2号的交易内容"
- 任何包含"交易"关键词的询问

## 参数提取规则

### 日期处理（必选）

**日期识别规则**：
- 用户必须提供日期信息，否则必须引导用户提供
- 日期可以是**具体某一天**：`"2025年1月2日"`、`"2025-01-02"`
- 日期可以是**一个范围**：`"2025年1月"`、`"2025年1月1日到1月31日"`、`"1月2号到2月2号"`
- 范围**最多不超过31天**，否则提示用户缩小范围

### 日期缺失处理

用户未提供日期时，必须主动询问：
> "请问您需要查询哪一天的交易数据？您可以指定具体日期（如'2026年4月1日'），或者一个日期范围（如'2026年4月1日到4月30日'），日期范围最多不超过31天。"


### 可选筛选条件

- `exchange_name`：交易所名称（大连商品交易所、上海期货交易所、郑州商品交易所、中国金融期货交易所）
- `variety_id`：品种代码
- `contract_id`：合约代码


## 调用工具

调用 `query_delivery_data` 工具，参数构造示例：

### 参数构造规则

| 用户输入 | 提取结果 | 参数传递 |
|:---|:---|:---|
| "查1月2号" | 2025年1月2日（使用当前年度） | `start_date`: "2025-01-02", `end_date`: "2025-01-02" |
| "查2025年1月2号" | 精确日期 | `start_date`: "2025-01-02", `end_date`: "2025-01-02" |
| "查1月2号到1月31号" | 日期范围 | `start_date`: "2025-01-02", `end_date`: "2025-01-31" |
| "查1月2号到2月15号" | 超出31天 | 提示用户范围超限，需要缩小 |
| "查1月2号的大连交易所" | 日期+交易所 | `start_date`: "2025-01-02", `end_date`: "2025-01-02", `exchange_name`: "大连商品交易所" |


### 使用示例

**单日查询**：用户问"帮我查询2025年1月2号的交易内容" -> 调用 `query_delivery_data`
```json
{
  "start_date": "2025-01-02",
  "end_date": "2025-01-02"
}
```

**范围查询**：用户问"查询2025年1月1日到1月15日的交易数据" -> 调用 `query_delivery_data`
```json
{
  "start_date": "2025-01-01",
  "end_date": "2025-01-15"
}
```

**按交易所筛选**：用户问"帮我查询2025年1月2号的大连商品交易所的交易内容" -> 调用 `query_delivery_data`
```json
{
  "start_date": "2025-01-02",
  "end_date": "2025-01-02",
  "exchange_name": "大连商品交易所"
}
```

**按品种筛选**：品种需要查询转换为对应的**品种代码**再chuan，用户问"查询2025年1月2号的豆粕交易内容" -> 调用 `query_delivery_data`
```json
{
  "start_date": "2025-01-02",
  "end_date": "2025-01-02",
  "variety_id": "M"
}
```

**完整筛选**：用户问"查2025年1月2号大连交易所螺纹钢M2505合约" -> 调用 `query_delivery_data`
```json
{
  "start_date": "2025-01-02",
  "end_date": "2025-01-02",
  "exchange_name": "大连商品交易所",
  "variety_id": "RB",
  "contract_id": "RB2501"
}
```

### 输出格式

#### 1. 合法范围查询返回（范围 ≤ 31天）

返回该范围内**所有日期**的交易数据，`data` 数组按日期排序：

```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "delivery_date": "2025-01-02",
      "exchange_id_name": "大连商品交易所",
      "exchange_id": "DCE",
      "variety_id": "M",
      "contract_id": "M2501",
      "delivery_content": "标准仓单交易，1000吨"
    },
    {
      "delivery_date": "2025-01-05",
      "exchange_id_name": "上海期货交易所",
      "exchange_id": "SHFE",
      "variety_id": "RB",
      "contract_id": "RB2501",
      "delivery_content": "品牌交易，5000吨"
    },
    {
      "delivery_date": "2025-01-10",
      "exchange_id_name": "郑州商品交易所",
      "exchange_id": "CZCE",
      "variety_id": "SR",
      "contract_id": "SR2501",
      "delivery_content": "白糖标准仓单，2000吨"
    }
  ]
}
```

#### 2. 无数据返回

```json
{
  "code": 0,
  "message": "success",
  "data": []
}
```

#### 3. 范围超限错误

当日期范围超过31天时，**不调用工具**，直接提示用户：

```json
{
  "code": 400,
  "message": "error",
  "error": "日期范围不能超过31天，请缩小范围后重试"
}
```

> **提示用户**："您查询的日期范围（1月2日到2月18日）共48天，已超过31天的限制。为了保证查询效率，请将范围缩小至31天以内，例如'1月2日到2月2日'。"

```

查询结果：
| 交易日期 | 交易所 | 品种 | 合约 | 交易内容 |
|:---|:---|:---|:---|:---|
| 2025-01-02 | 大连商品交易所 | M | M2501 | 标准仓单交易，1000吨 |
| 2025-01-05 | 上海期货交易所 | RB | RB2501 | 品牌交易，5000吨 |
| 2025-01-10 | 郑州商品交易所 | SR | SR2501 | 白糖标准仓单，2000吨 |

```
正在为您查询 2025年1月2日 的交易数据...

查询结果：暂无数据

该日期暂无交易记录，或您可以尝试调整筛选条件。
```

为保证查询效率，请将范围缩小至31天以内，例如：
- "2025年1月2日到2月2日"
- "2025年1月整月"

请问您需要如何调整？
```
